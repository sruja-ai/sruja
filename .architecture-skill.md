# Sruja architecture guidance for AI

Use Sruja in your AI code editor so the assistant generates valid Sruja DSL and applies architectural patterns (C4-style components, relationships, monolith vs microservices, event-driven, etc.).

## Install as a skill (one command)

**Cursor, Codex, or any editor using [skills.sh](https://skills.sh):**

```bash
npx skills add https://github.com/sruja-ai/sruja --skill sruja-architecture
```

After install, the agent can use the full guide (principles, patterns, anti-patterns, trade-offs).

## Other editors

- **Cursor (project rules only)** – Copy [.cursorrules](.cursorrules) into your project root for DSL syntax and basic patterns.
- **GitHub Copilot** – Copy [.copilot-instructions.md](.copilot-instructions.md) into your project root.
- **Full install guide** – [docs/INSTALL_AS_SKILL.md](docs/INSTALL_AS_SKILL.md) – by-editor steps, Cursor options, and optional skills (architecture-agent, collaboration).

## After install

- Run **`sruja lint`** on any `.sruja` file after the AI edits it.
