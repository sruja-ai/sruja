# Workflow: Live Architecture Session

## Description

Real-time collaborative architecture design session with multiple agents.

## Session Structure

### Pre-Session Setup

```
1. Facilitator creates workspace
2. Analyst pre-gathers context
3. Define session goals
4. Set timebox (max 2 hours)
5. Invite required agents
```

### Session Start (5 min)

```
1. Facilitator introduces participants
2. Analyst presents context summary
3. Define success criteria
4. Confirm timebox
```

### Active Design (60-90 min)

```
1. Architect presents initial design
2. Reviewer provides real-time feedback
3. Collaborative refinement
4. Progress checkpoints every 30 min
5. Validator runs checks
```

### Session Wrap (10 min)

```
1. Summarize decisions made
2. Document open items
3. Assign follow-ups
4. Schedule next session if needed
5. Archive session artifacts
```

## Timebox Guidelines

| Phase | Duration |
|-------|----------|
| Start | 5 min |
| Design | 60-90 min |
| Wrap | 10 min |
| Total | Max 2 hours |

## Checkpoint Protocol

Every 30 minutes:

```
1. Facilitator: "Checkpoint - where are we?"
2. Summarize current state
3. Check against goals
4. Adjust if needed
5. Continue or park items
```

## Concurrent Editing

```
Rules for live editing:

1. One agent edits at a time
2. Changes attributed to role
3. Facilitator resolves conflicts
4. Major changes discussed first
5. All changes logged
```

## Parking Lot

```
For off-topic or complex items:

1. Document item
2. Note why parked
3. Assign owner
4. Schedule follow-up
5. Don't lose it
```

## Best Practices

- Start on time
- Stay focused on goal
- Use parking lot liberally
- Check in regularly
- End on time
- Document everything

## Anti-Patterns

- ❌ No clear goal
- ❌ Running over time
- ❌ Not using parking lot
- ❌ One person dominating
- ❌ Not documenting decisions
- ❌ Skipping checkpoints
