# Courses

Structured courses to learn architecture-as-code with Sruja, from fundamentals to production patterns.

| Course                                                                | Description                                                                     |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| [Systems Thinking 101](systems-thinking-101/course-overview.md)       | Fundamentals, parts & relationships, boundaries, flows, feedback loops, context |
| [System Design 101](system-design-101/course-overview.md)             | Fundamentals, building blocks, advanced modeling, production readiness          |
| [System Design 201](system-design-201/course-overview.md)             | High throughput, real-time, data-intensive, consistency                         |
| [Ecommerce Platform](ecommerce-platform/course-overview.md)           | Vision, architecture, SDLC, ops, evolution, governance                          |
| [Production Architecture](production-architecture/course-overview.md) | Performance, modular design, governance                                         |
| [Agentic AI](agentic-ai/course-overview.md)                           | Fundamentals, patterns, modeling for AI systems                                 |
| [Advanced Architects](advanced-architects/course-overview.md)         | Policy as code and advanced topics                                              |

Start with **Systems Thinking 101** or **System Design 101** if you're new; use the [Beginner path](../docs/beginner-path.md) to combine courses with tutorials and challenges.
