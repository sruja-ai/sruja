# Quick Reference Guide
**Systems Thinking 101 Humanization Project**

Use this guide while rewriting lessons. Keep it open alongside your editing window.

---

## 🎯 Golden Rules

1. **Start with a hook** - Question, story, or relatable scenario (NOT a definition)
2. **Use "Learning Goals" (plural)** - Never "Learning Goal" (singular)
3. **Vary headings** - Never use "What is/What Are [Topic]?" every time
4. **Write paragraphs, not just bullets** - Aim for 60:40 ratio
5. **Add transitions** - Connect sections naturally
6. **Vary quiz formats** - Don't use identical HTML for every question
7. **Always add "What's Next"** - Link to the next lesson

---

## 📝 Opening Hooks (Copy & Paste)

**Questions:**
- "Have you ever [problem]? [Why it's painful]."
- "Think about a time when [experience]. [What happened]."
- "What happens when [scenario]? [Why it matters]."

**Stories:**
- "Let me share a quick story from my experience..."
- "I once worked on [project] where [problem]."
- "Here's something you've probably experienced: [relatable scenario]."

**Scenarios:**
- "Imagine you're [situation]. [What happens]."
- "Consider this scenario: [description]."
- "Let's start with something you've probably seen: [example]."

---

## 🔄 Transition Phrases (Copy & Paste)

**Between sections:**
- "Now that we've covered [X], let's look at [Y]."
- "This raises an important question: [Y]."
- "Here's where [X] gets interesting."
- "Let's see this in practice with an example."
- "So far, we've focused on [X]. Now, consider [Y]."
- "Building on this, let's explore..."
- "This brings us to another important concept."

**Before examples:**
- "To make this concrete, let's look at..."
- "Here's a real-world example:"
- "Consider this scenario:"
- "Let's apply this to something you've probably seen:"
- "An example will help clarify this:"
- "I've seen this pattern play out many times:"

**After examples:**
- "This example shows..."
- "What's happening here?"
- "Notice how..."
- "The key insight is..."
- "This pattern is common because..."
- "Here's why this matters:"

**Before activities:**
- "Let's try this:"
- "Here's something to think about:"
- "Time to apply what you've learned:"
- "Your turn:"
- "Let's put this into practice:"

## 🏷️ Heading Variations (Never repeat "What is/What Are")

**For introducing concepts:**
- "Understanding [Topic]"
- "[Topic] in Practice"
- "Getting Started with [Topic]"
- "How [Topic] Works"
- "[Topic]: The Basics"
- "The Big Picture: [Topic]"
- "[Topic] Explained"

**For diving deeper:**
- "[Topic] in Action"
- "Putting [Topic] to Work"
- "When to Use [Topic]"
- "Common [Topic] Patterns"
- "Advanced [Topic] Techniques"
- "Mastering [Topic]"

**For examples:**
- "Real-World Example"
- "[Topic] in Everyday Life"
- "A Concrete Example"
- "[Topic] at Work"
- "Let's See It in Action"

**For summaries:**
- "Putting It All Together"
- "What to Remember"
- "Key Insights"
- "The Main Point"
- "Bringing It Home"

## ✅ Quick Checklist Per Lesson

**Before publishing:**
- [ ] Summary in frontmatter is engaging (question/hook)
- [ ] Uses "Learning Goals" (plural)
- [ ] Main heading varies (NOT "What is/What Are")
- [ ] Starts with hook (question or story)
- [ ] Has conversational transitions between sections
- [ ] Mixes paragraphs with bullets (not all bullets)
- [ ] Replaced "Key Takeaways" with varied heading
- [ ] Summary uses paragraphs, not just bullets
- [ ] Quiz formats vary (not identical HTML)
- [ ] Added 1-2 reflection questions
- [ ] Has "What's Next" section

**Style check:**
- [ ] Uses "you" consistently
- [ ] Has 3+ rhetorical questions
- [ ] No "In conclusion," "Furthermore," "It's important to note"
- [ ] Reads like conversation, not lecture
- [ ] Would a human mentor say this?

## ❌ Common Pitfalls to Avoid

**Don't:**
- Start every lesson with "What is/What Are [Topic]?"
- Use identical quiz HTML for all questions
- Write everything as bullet points
- Have "Key Takeaways" in every lesson with same format
- Use perfect symmetry in section lengths
- Over-structure simple explanations in code blocks
- Start definitions with "**[Topic]** is..." every time

**Do:**
- Vary heading styles
- Mix prose with lists naturally
- Write full paragraphs for explanations
- Add personal touches ("Let me share...")
- Use rhetorical questions
- Make sections different lengths naturally
- Add conversational transitions

## 💡 Pro Tips

1. **Read aloud** - If it sounds robotic, rewrite it
2. **Use "we" and "you"** - Creates connection
3. **Tell stories** - Personal anecdotes make it human
4. **Ask questions** - Even rhetorical ones engage readers
5. **Be encouraging** - "You're practicing..." not "You should..."
6. **Vary sentence length** - Short, medium, long for rhythm
7. **Add emphasis naturally** - Bold, italic, not just bold

## 🎯 Example Comparison

**Before (AI-style):**
```
## What Are Flows?

Flows represent how information moves through a system.

### Why Flows Matter
Flows show data lineage and bottlenecks.
```

**After (Human-style):**
```
## How Flows Work

So far, we've looked at systems as snapshots—showing what parts exist and how they're connected. But real systems aren't static. Data moves, actions trigger other actions, and users follow paths through your application.

**Flows** capture this movement. They show you not just what's connected, but how things flow through the system over time.

### Why This Matters

Understanding flows helps you answer questions like:
- Where does this data actually come from?
- What happens when a user clicks this button?
- Where are the bottlenecks in this process?
```

## 🚀 Quick Start for Each Lesson

1. Read original lesson (5 min)
2. Choose template (A, B, or C)
3. Write opening hook with question or story (10 min)
4. Write 2-3 paragraphs before first code example (10 min)
5. Rewrite examples with conversational explanations (20 min)
6. Rewrite misconceptions/tips naturally (10 min)
7. Rewrite summary as paragraphs (10 min)
8. Vary quiz format, add reflection questions (15 min)
9. Add "What's Next" section (5 min)
10. Check against checklist (5 min)

**Total: ~90 minutes per lesson**
