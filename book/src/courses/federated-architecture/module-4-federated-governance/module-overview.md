# Module 4 - Federated Governance

**Federated policies, compliance reporting, and governance automation.**

## Overview

This module teaches how to implement governance that scales across all repos.

## Lessons

### Lesson 1: [Federated Policies](lesson-1.md)
_Define policies that span repos_

- Policy inheritance
- Policy overrides
- Policy composition

### Lesson 2: [Compliance Reporting](lesson-2.md)
_Generate cross-repo compliance reports_

- Compliance dashboard
- Per-team reports
- Drift reporting

### Lesson 3: [Governance Automation](lesson-3.md)
_Automate governance with CI/CD_

- Policy enforcement in CI
- Automated remediation
- Governance metrics

## Learning Outcomes

- ✅ Define federated policies
- ✅ Generate compliance reports
- ✅ Automate governance in CI/CD
