# Advanced Views

Demonstrates custom view features with multiple perspectives on an e-commerce system.

## Views Defined

- **API Architecture** - Shows API layer and database
- **Customer Experience** - Components visible to customers
- **System Context** - External actors and system overview
- **Data Layer** - Shows databases and their consumers
