# Sruja architecture guidance for AI

Quick-start files in this project (`.cursorrules`, `.copilot-instructions.md`) give **DSL syntax and basic patterns** for Sruja.

For **full architectural guidance** (principles, patterns, anti-patterns, trade-offs like monolith vs microservices, event-driven, CQRS), install the Sruja Architecture skill:

```bash
npx skills add https://github.com/sruja-ai/sruja --skill sruja-architecture
```

After install, agents can use the compiled guide at `skills/sruja-architecture/AGENTS.md`.

- **Docs:** [AI Editor Integration](docs/AI_EDITOR_INTEGRATION.md)
- **Skill registry:** https://skills.sh
